# Project 07 — DHCP and DNS Services

## Objective

Deploy and troubleshoot core network services used by client systems.

## DHCP Topics

- DHCP scope
- Address pool
- Default gateway option
- DNS server option
- Lease
- Reservation
- DORA process

## DNS Topics

- Resolver
- A / AAAA records
- Forward and reverse lookup
- Recursive queries
- Caching
- Troubleshooting name resolution

## Verification Commands

```bash
ipconfig /all
nslookup example.com
ping <hostname>
```

Linux equivalents should also be documented.
