# Project 12 — Security and Hardening

## Objective

Apply practical security controls to lab systems without treating security as a checklist-only exercise.

## Planned Tasks

- Disable unnecessary services
- Use least-privilege accounts
- Configure SSH securely
- Apply host firewall rules
- Install updates
- Review listening ports
- Protect administrative interfaces
- Segment systems using VLANs
- Back up important configuration

## Evidence

For each control explain:

- Risk being reduced
- Configuration made
- How the change was verified
- How access would be recovered if the configuration caused a lockout
