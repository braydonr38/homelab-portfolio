# Project 03 — Linux Server Administration

## Objective

Deploy a Linux server VM and practice common systems administration tasks.

## Planned Tasks

- Install Linux server
- Create administrative and standard users
- Configure SSH
- Manage packages
- Manage services with systemd
- Review logs
- Configure hostname
- Configure networking
- Set file ownership and permissions
- Use basic firewall rules
- Perform updates
- Practice remote administration

## Evidence

Capture useful command output such as:

```bash
ip addr
ip route
ss -tulpn
systemctl status <service>
journalctl
df -h
free -h
```

Never commit passwords, private keys, tokens, or other secrets.
