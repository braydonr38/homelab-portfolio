# Project 06 — Inter-VLAN Routing

## Objective

Allow controlled Layer 3 communication between selected VLANs and document how traffic moves between networks.

## Concepts

- Default gateways
- Layer 3 routing
- Subnets
- Inter-VLAN routing
- Routing tables
- ICMP testing
- Traffic isolation

## Verification

Prove:

- Same-VLAN communication works.
- Cross-VLAN communication fails before routing is enabled.
- Cross-VLAN communication works after routing is correctly configured.
- Routing table entries match the intended topology.
