# Project 09 — Static Routing Lab

## Objective

Build multiple IP networks and manually control how packets reach remote networks.

## Concepts

- Connected routes
- Static routes
- Next-hop IP
- Exit interface
- Default route
- Longest-prefix match
- Routing table verification

## Cisco Practice

Packet Tracer will be used where Cisco IOS commands provide better CCNA practice.

Example commands to understand and document:

```text
show ip route
show ip interface brief
ip route <network> <mask> <next-hop>
```
