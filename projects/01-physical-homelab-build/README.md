# Project 01 — Physical Homelab Build

## Objective

Build a stable physical foundation for a networking and systems administration homelab without disrupting the normal home network.

## Environment

- Spectrum router
- TP-Link managed switch
- Dell OptiPlex 5070 Micro
- Main administration PC
- Ethernet cabling

## Work Completed

- Installed and inspected server hardware.
- Verified system diagnostics.
- Enabled Intel virtualization features.
- Connected the server to the wired LAN.
- Added the managed switch to the network.
- Prepared the server to run headless after initial setup.

## Concepts Practiced

- LAN topology
- Ethernet cabling
- Switch connectivity
- IP addressing
- Default gateway
- DHCP
- DHCP reservation
- Headless server administration

## Verification

Evidence to capture:

- Switch and server physical setup
