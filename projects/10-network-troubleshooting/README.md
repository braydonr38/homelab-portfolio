# Project 10 — Network Troubleshooting Scenarios

## Objective

Intentionally break lab configurations and troubleshoot them using a repeatable process.

## Planned Failure Scenarios

- Wrong IP address
- Wrong subnet mask
- Wrong default gateway
- DNS failure
- Disabled interface
- Wrong VLAN assignment
- Trunk mismatch
- Missing route
- Duplicate IP
- Service stopped
- Firewall blocking traffic

## Troubleshooting Method

For every scenario document:

1. User-visible symptom
2. Initial hypothesis
3. Commands/tools used
4. Layer being tested
5. Root cause
6. Corrective action
7. Verification

## Tools

- `ping`
- `tracert` / `traceroute`
- `ipconfig`
- `ip addr`
- `ip route`
- `arp`
- `nslookup`
- `ss`
- Packet capture tools
- Switch management interface
- Proxmox console
