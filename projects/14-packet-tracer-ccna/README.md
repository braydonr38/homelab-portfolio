# Project 14 — Cisco Packet Tracer CCNA Labs

## Objective

Use Cisco Packet Tracer to practice CCNA objectives that cannot be fully reproduced with the physical homelab.

## Lab Categories

- Basic Cisco IOS configuration
- IPv4 addressing
- Subnetting
- VLANs
- Trunks
- Router-on-a-stick
- Static routes
- Default routes
- OSPF
- EtherChannel
- STP
- DHCP
- NAT
- ACLs
- IPv6
- Wireless concepts
- Network troubleshooting

Each lab should include a topology image, configuration files or commands, verification output, and a short explanation of why the configuration works.
