# Project 08 — Pi-hole DNS Filtering

## Objective

Deploy Pi-hole as a DNS-based filtering service while learning how DNS requests move through the network.

## Skills Demonstrated

- Linux server deployment
- DNS configuration
- Static addressing / DHCP reservation
- Service administration
- Client DNS configuration
- Query logging
- Troubleshooting

## Verification

Document:

- Pi-hole host configuration
- DNS server settings
- Client resolution tests
- Query log evidence
- Failure/recovery test if Pi-hole becomes unavailable

## Operational Consideration

The normal home network should remain usable and recoverable. Changes that could affect gaming or work connectivity should include a rollback plan.
