# Project 05 — VLAN Segmentation Lab

## Objective

Segment the homelab into multiple logical networks and verify that Layer 2 isolation behaves as expected.

## Planned VLANs

Exact VLAN IDs and subnets will be chosen during implementation.

Potential roles:

- Management
- Servers
- Clients
- Isolated / Guest

## Questions This Project Should Answer

- What problem does a VLAN solve?
- What is an access port?
- What is a trunk?
- What is an 802.1Q tag?
- Why can two devices on different VLANs not communicate without Layer 3 routing?

## Verification

Use ping, ARP tables, switch VLAN configuration, and packet captures where useful.
